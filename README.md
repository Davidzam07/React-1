# 🌟 Bienvenido a AURAX 

Este proyecto nació con un objetivo claro: crear una experiencia de compra donde la moda y la tecnología se encuentran de la manera más simple y elegante posible.

## 💫 La Historia Detrás

AURAX no es solo una tienda online. Es el resultado de combinar mi pasión por el desarrollo web con el deseo de crear algo único. Cada línea de código fue escrita pensando en ofrecer una experiencia de compra excepcional.

## ✨ Lo Que Hace Especial a AURAX

Cuando entras a AURAX, encontrarás:
- Un catálogo que se adapta a tus necesidades
- Categorías organizadas para encontrar lo que buscas fácilmente
- Un carrito inteligente que guarda tus selecciones
- Un proceso de compra simple y seguro

## 🚀 El Viaje de Desarrollo

Para dar vida a AURAX, usé:
- React, porque quería una experiencia fluida y moderna
- Firebase, para manejar los datos de forma segura y eficiente
- CSS puro, para darle ese toque personal y único

## 🛠️ ¿Quieres Probarlo?

Es muy fácil:
1. Descarga el proyecto
2. Instala las dependencias con `npm install`
3. Inicia el servidor con `npm run dev`
4. ¡Y listo! Empieza a explorar

## 🌈 El Futuro

AURAX sigue creciendo. Cada día trabajamos para agregar nuevas funcionalidades y mejorar tu experiencia de compra.
